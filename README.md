##Summary RNA_Seq data (370.8GB) for Solanum lycopersicum were obtained from https://www.ncbi.nlm.nih.gov/bioproject/?term=PRJNA641520 and quantified with Kallisto against the SL3.1 reference genome. RNA-Seq reads were pseudoaligned and quantified against the Solanum lycopersicum SL3.1 reference genome using kallisto in a conda environment on Linux (Ubuntu 26.04). Six samples (3 biological replicates per condition) were compared: Cooler (20/12 °C day/night) vs. Warm (24/20 °C day/night).

A single-factor DESeq2 model (~ condition) was fitted after filtering genes with a total count <= 200 (17,170 retained). Data quality was confirmed via PCA (replicates clustered by condition) and a dispersion plot. Differential expression was tested for the contrast Warm vs. Cooler (BH-adjusted p less than 0.05, |log₂FC| greater than 1), yielding 3,780 DEGs.

Results were visualised as MA, volcano, and z-scored clustered heatmap (top 50 DEGs) plots. GO biological process enrichment (clusterProfiler, S. lycopersicum OrgDb via AnnotationHub) was performed on up- and down-regulated DEGs separately. The up-regulated set was enriched for cell wall biogenesis/remodelling (xyloglucan metabolism, cell wall polysaccharide metabolism) and cytokinin biosynthesis/signalling, indicating growth-promotion rather than a heat-stress response.
